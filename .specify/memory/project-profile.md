## Architecture

- **Pattern**: Single Go desktop app with layered internals.
- **Entry point**: `cmd/fallout-tracker/main.go`.
- **Domain**: `internal/domain` defines campaigns, encounters, combatants, resources, resistance, damage/healing, validation, and difficulty metrics.
- **Application**: `internal/app` exposes use-case services and repository contracts.
- **Persistence**: `internal/store/sqlite` implements repositories, transactions, migrations, sqlc mappings, and DB tests.
- **Presentation**: `internal/ui/fyneui` implements Fyne dialogs, views, presenters, collectors, formatting, and refresh behavior.

- **Generated code**: sqlc output under `internal/store/sqlite/dbgen` is generated and should not be hand-edited.
